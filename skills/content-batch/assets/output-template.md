# Output template

```
Voice: [handle] — [snapshot]
Cluster: [one line]
Window: [e.g. 5 days]
Mix: [news-beat | builder-beat | thin-feed]
Goal: [inform | ship-log | audience-build | launch-adjacent]

Day 1 — [container] · [template or job]
[copy]
[N] ch
Source: ...

Day 2 — [container] · [template or job]
Parent: @[handle] — [one-line]   ← if reply or quote
[copy]
[N] ch
Source: ...

...

Why this mix: [one sentence]
Balance: [two+ containers · no repeated hook · sources present]

Slot alts
Day 1 alt: ...
Day 3 alt: ...
Day 4: thread kept | collapsed to short-claim because [reason]
```

Paste-ready per slot. Character counts on every original and reply. If a slot is a reply or quote, include the parent handle and a one-line summary of the parent. If the parent is not fetched yet, write `find parent:` and the search, do not invent a fake @.
