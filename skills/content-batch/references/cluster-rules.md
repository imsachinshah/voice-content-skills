# Cluster rules

The cluster is the *subject*, not the headline copied seven times.

## Contents

- One cluster
- Example
- Sources
- Fail closed

## One cluster

A cluster is one object you can point at:

- A filing, issuance, or rail (REC tokenised bond / T+1)
- A shipped change (deploy 40m → 6m)
- A beat week (one policy, one product)

Not a cluster:

- "Crypto + AI + my startup + GM"
- Five products
- "Thoughts on the market"

If the user hands you five topics, pick one with them. Put the rest in a parking line, not in the week.

## Example shape (pattern, not copy)

Cluster: "India tokenised bonds / T+1"

- Mon: REC number + mechanism (single)
- Tue: reply under a global RWA thread with the India number
- Wed: why T+1 is the product (explanatory-why)
- Thu: skip thread if Wed closed it
- Fri: quote a US settlement take, add the local number

Same cluster. Five different jobs.

## Sources

News and markets:

- Official posts, filings, company blogs
- CoinDesk / The Block / WSJ when they are the report
- Mark "reported" / "filing says" when it is not final

Do not draft a week off a rumor screenshot. One unverified slot kills the pack.

Builder weeks:

- Real numbers from their work
- No invented "we grew 10x"
- Misses allowed; fake wins are not

## Fail closed

Do not draft the week when:

- Cluster is still "everything"
- Voice Card cannot be filled and they refused a default
- The only honest week is seven restatements of one headline — write one tweet instead
- They actually wanted an article
