# Slot jobs

Map each day to a named template or reply job. Do not invent a parallel vocabulary.

Originals use `viral-tweets` names. Replies use `viral-replies` names.

## Contents

- Original slots
- Reply / quote slots
- Thread slots
- Hand-off

## Original slots

| Mix job | Template to name | When |
|---|---|---|
| the week's fact | fact-mechanism | Number + named entity exist |
| they already know the headline | explanatory-why | Hours after, not instead of |
| they have felt this | lived-scene | Scene, not topic label |
| stealable line | short-claim | 13–25 words, sharp |
| shipped / missed | bip-week or specific-result | Builder feeds only |
| exposing plan | goal-share | Max once per week |

Do not force goal-share or confession onto a news item the account did not live.

## Reply / quote slots

| Mix job | Reply job | When |
|---|---|---|
| add under a larger post | add-mechanism | Parent skipped the local number or rail |
| translate | translate-local | Global parent, local audience |
| lived proof | witness-scene | You have the scene |
| second-order on your timeline | quote-add | Take deserves *your* reach |

Find a real parent before drafting the reply slot. "Reply to someone in RWA" is not a parent. Fetch or ask.

If the parent is a small account, reply — do not quote-dunk.

## Thread slots

Only when 280 cannot hold it. Name one structure:

breakdown · tension-resolution · sourced-explainer · story-turn · if-x-do-y

Run the `viral-tweets` autopsy (tweet 1 standalone, tweet 2 pays, no prior-pronoun). If it fails, collapse to a single.

## Hand-off

| Slot looks like… | Skill |
|---|---|
| One original | `viral-tweets` rules |
| Under someone else's post | `viral-replies` rules |
| Headings / table / filing quote that needs dwell | `viral-articles` — stop the week |
| Bio / pin | `x-profile` — not a week slot |
