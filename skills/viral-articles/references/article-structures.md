# Article structures

Pick one. Label it in the output.

### thesis-essay
Claim → stakes → 3 proofs → objection → implication.  
For a take you would defend in replies.

### sourced-explainer
What the document says → the clause that matters → how the machine works → who is affected → what to watch.  
Default for news, markets, policy.

### guide
Promise an outcome. Each H2 is a step with one artifact. Close on the failure mode.

### story-turn
Scene → wrong approach → turn → mechanism kept → the claim the story earned.  
Only if the writer lived it.

## Section craft

- H2s are questions or claims, not labels ("Background")
- One artifact per section
- Vary section length
- Mark uncertainty ("filing says", "reported")
- First person only if the Voice Card uses it
