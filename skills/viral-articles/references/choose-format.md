# Choose format

Ask three questions. Two yeses decide.

1. Will someone reopen this in a week?
2. Does it need headings, a table, a code block, or a document crop?
3. Is the value depth (one teardown) or sequence (ten beats)?

| Result | Format |
|---|---|
| Two+ depth / reopen / structure | Article (X, Substack, blog) |
| One continuous take, no H2s | Premium long post |
| Sequence / replies / live news beats | Thread — hand off to `viral-tweets` |

## Jobs

- Thread — reach and conversation. Dies if tweet 1 fails. Decays fast.
- Long post — one take in the feed. Hard to skim.
- Article — dwell, bookmarks, a URL that still works next week. Extra tap, so the first screen must earn it.

## Defaults

- News mechanism that needs a filing quote → Article (sourced explainer)
- Hot take with 4 proof beats → Thread
- Weekly shipped/missed/next → tweet, not an article
- "7 things I wish I knew" → neither. Rewrite as a thesis or kill it.
