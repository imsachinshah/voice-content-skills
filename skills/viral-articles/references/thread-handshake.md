# Thread handshake

Write the article first so the thread cannot invent facts.

Then lift three payloads:

1. Hook tweet — title energy + number or named entity
2. Best mechanism tweet — the clause or how-it-works line
3. Implication tweet — the close, shortened

Optional tweets 4–5 only if they screenshot cleanly alone.

Rules:

- No link in tweet 1. Put the Article URL in the first reply.
- No "new article just dropped."
- A day later, one quote-tweet with a second-order take, not a second launch.
- If the idea no longer needs depth after the lift, you chose the wrong container.

Hand the tweet pack to `viral-tweets` output rules if that skill is loaded — same voice card, character counts, no dead costumes.
