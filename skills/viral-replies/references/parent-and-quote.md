# Parent and quote

Use this in step 1 (lock the parent) and whenever the container is unclear.

## Contents

- Fetch
- Already said

- Fail closed

## Fetch

Need the actual post. Bio + rumor screenshot is not a parent.

1. Parse handle + status if a URL exists.
2. `x_thread_fetch` for the post and nearby replies.
3. Read tweet 1 of a thread, not only the tweet they linked, when the linked tweet is 4+.
4. Skim 2–3 existing replies that already have payload. Do not duplicate them.

If fetch fails, ask the user to paste the parent text. Do not draft off the URL alone.

## Already said

If two visible replies already made your add, you do not have an add.

- Same number, same mechanism, same "this, but in India" → skip or pick a different job.
- A worse version of your add is already there → you may still write it if yours has the artifact they missed.
- 40 "great point" replies do not count as coverage.

## Reply vs quote-tweet

| | Reply | Quote-tweet |
|---|---|---|
| Goal | Be useful *to them and their readers* | Publish your take, using theirs as evidence |
| Linkage | Under the post | Your timeline |
| Length | Shorter (default <160) | Can be a full tweet |
| Fail mode | Generic praise | Restating the quote |

Default to a **reply** for a question, a correction, or a local add their readers need.

Default to a **quote-tweet** when the second-order take should reach *your* followers.

A quote-tweet that just says "this" plus the original is a reply with extra steps. Add or do not quote.

## Small accounts

Never quote-dunk a smaller account. Add value as a reply or skip.

A named correction of a load-bearing error is allowed in a reply, without insult. The artifact does the work.

## Stale threads

If the parent is days old:

- A late reply is fine when you are answering *them*.
- A late "me too" is noise.
- A strong leftover take → quote-add or a new original (`viral-tweets`), not a necro-reply.

## Fail closed

Do not draft when:

- You cannot see the parent text
- The only honest job is agree
- The add is unsourced news
- The user asked to dunk
