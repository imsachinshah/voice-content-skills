# Reply rules

Use this on every draft before shipping. Container choice lives in [parent-and-quote.md](parent-and-quote.md).

## Contents

- Length
- First six words
- Specificity tests
- Voice
- Goldilocks
- Retired costumes
- Pre-send

## Length

- Default: one breath. Under 160 characters.
- Hard ceiling: 280. Emoji counts as 2.
- If you need more, you picked the wrong container — original or article, not a reply.
- Line breaks: match the Voice Card. Most replies are one block.

## First six words

Must contain a specific: name, number, mechanism, or a clause from the parent.

Fail: "Love this take on markets."
Pass: "The T+1 wait is the actual product REC just skipped."

Preview cutoff is still ~70–90 characters even under someone else's post. Put the load-bearing words first.

## Specificity tests

1. Would this reply still make sense under a different viral tweet? If yes, kill it.
2. Can you point at the clause you are answering?
3. Is the new information sourced or clearly marked as opinion?
4. Did an existing reply already say this? If yes, pick another payload or skip.

## Voice

- Copy *your* account, not the parent.
- If they never reply with emoji, you don't either.
- If they reply in Hinglish, one Hinglish clause is allowed. Do not costume it.
- Grateful replies only if the Voice Card already does that, and only after a payload.
- One idea. If you have two, pick the stronger.
- End on a landing, not "what do you think?"

## Goldilocks tests

Run these on the first line:

1. Can a stranger in the niche name the add in one phrase? If not, the reply is fog.
2. Does the rest actually close it?
3. Are the load-bearing words inside the first 70–90 characters?
4. Would the line still work after stripping "this.", "so true.", and emoji?
5. Is the gap closable *here*, or does it demand a thread?

## Retired costumes

These used to be interrupts. In 2026 they *are* the pattern. Do not use unless the Voice Card shows the account already lives on them:

- "Came here to say this"
- "Taking notes"
- "The algorithm needs to push this"
- "Who else is seeing this?"
- "Let's gooo" / "W" / "Based"
- "Bookmarking this"
- "Not gonna lie" / "Let me be honest" / "Here's the thing"
- Any reply that would work under 50 other posts

## Pre-send

Delete before shipping:

- [ ] Hedges with no fact ("might", "could be huge")
- [ ] Invented numbers, "I've been saying this," fake metrics
- [ ] Restatement of the parent
- [ ] Product link they did not ask for
- [ ] Second idea
- [ ] Character overflow (count after writing, emoji = 2)
