## Why hooks work

A feed is autopilot. The first line has ~1–2 seconds and ~70–90 visible characters to beat the skip filter.

A stop happens when the line trips at least two of: pattern break, personal relevance, emotional charge, threat or opportunity.

After the stop, the line must leave enough tension that the reader expands the tweet or taps the thread.

## Four circuits

### Information-gap curiosity (Loewenstein)

Curiosity is deprivation, not delight. It starts when the reader notices a gap between what they know and what they want to know.

- Total ignorance creates no curiosity. Anchor in knowledge the niche already has.
- Intensity tracks gap size × how closable the answer looks *in this post*.
- Open the gap before you dump the fact.

Best gap types for tweets:

- **Named thing** — one clause, one metric, one filing detail
- **Specific entity** — REC, RBI, a named product
- **Explanatory why** — they know the what; tease the mechanism

### Zeigarnik / open loops

Unfinished tasks occupy working memory. Start a story, a count, or a why and do not finish it in line one.

Use this to pull tweet 2, not as a memory trick. Always close the loop in the same post or thread. A loop that never pays off trains mutes.

### Pattern interrupt / incongruity

Scrolling is a script. Violate the predicted next post: contradiction, odd specificity, a sentence that does not look like a tweet.

Incongruity = expectation minus reality. Put the violation in the first 6–8 words.

### Loss, identity, specificity

- Loss aversion — cost of the status quo beats promised upside.
- Self-relevance — a scene the reader has lived beats a topic label.
- Specificity — a number triggers a fact-check reflex. "₹500 crore" is a claim. "Historic" is noise.
- Authority borrow — a named institution does the proving.

## Pick a circuit

| Reader state | Primary circuit | Amplifier |
|---|---|---|
| Does not know it happened | Specific number + named entity | Pattern interrupt |
| Knows it happened, not why | Explanatory gap | Mechanism close |
| Believes the opposite | Contradiction | Mechanism, not insult |
| Already feels the cost | Loss / lived scene | One number |
| Idea needs sequence | Open loop as 3-tweet thread | Entity in tweet 1 |

Default for news-style accounts:

**named fact + number** → **one mechanism** → **one-line take**

That is a closed, earned gap. Not a tease.

## Technique catalog

Rewrite every skeleton in the Voice Card. Skeletons are not output.

| Technique | Circuit | Do | Do not |
|---|---|---|---|
| Named gap | Loewenstein | Name the missing piece; imply this post closes it | "Nobody talks about this" with no object |
| Partial knowledge | Goldilocks gap | Start from what the niche knows, withhold the mechanism | "Big news in [topic]" |
| Open loop | Zeigarnik | Cut before the payoff; pay it off by tweet 2–3 | "Wait till the end 🧵" |
| Pattern interrupt | Orienting | First words should not look like every peer tweet | "Excited to share", "GM", "Huge news" |
| Specific number | Fact-check | Lead with the unit | "Huge", "massive", "historic" alone |
| Contradiction | Belief violation | Attack a real default belief, then explain | "Unpopular opinion:" as costume |
| Stakes / loss | Loss aversion | Name the cost of inaction | Vague FOMO |
| Scene, not topic | Self-relevance | Drop them in a situation | Topic labels ("thoughts on CBDC") |
| Authority borrow | Trust transfer | Named org, filing, product | "Experts say" |
| Explanatory gap | Strongest curiosity | Tease why, then answer | Tease why, then repeat the headline |
| Identity fork | Status / tribe | Let them recognize their side | Empty "GM bulls" |

## Goldilocks tests

Run these on every first line before shipping:

1. Can a stranger in the niche name the gap in one phrase? If not, the hook is fog.
2. Does the rest of the post actually close it?
3. Are the load-bearing words inside the first 70–90 characters?
4. Would the line still work after stripping "🧵", "👇", and "unpopular opinion"?
5. Is the gap closable *here*, or does it demand a blog post?

Curiosity peaks when the reader knows the domain, does not know this piece, and can get it in the next few seconds. Too little known = boredom. Too much unknown = skip.

## Clickbait vs earned gap

| Earned | Clickbait |
|---|---|
| Gap is a real fact, mechanism, or take | Gap is hype; payoff is a restatement |
| Close happens in the same post/thread | Close is "comment 'guide'" or a link dump |
| Specific entity + number | Adjective + mystery |
| Reader can steal the take | Reader feels tricked |

Never open a gap you cannot close with a sourced fact or a clearly marked opinion.

## Retired costumes

These used to be interrupts. In 2026 they *are* the pattern. Do not use unless the Voice Card shows the account already lives on them:

- "5 lessons" / "7 mental models"
- "Unpopular opinion:"
- "It's not X, it's Y"
- "Let that sink in" / "This is your sign"
- "What do you think? 👇"

The circuit stays. The costume changes. Write a new surface for an old mechanism.
