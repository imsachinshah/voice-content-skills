# Output templates

Lead with a one-line Voice Card summary, then the recommended draft, then alternatives. Keep meta short.

## Single tweet pack

```
Voice: [handle] — [3–6 word voice snapshot]
Brief: [topic] · [goal]
Recommended: [template] · [primary + amplifier]
Alt A: [template] · [circuit]
Alt B: [template] · [circuit]

Recommended
[tweet text]
[N] characters

Why this one: [template + circuit + voice + fact, one sentence]

Alt A — [template]
[tweet text]
[N] characters

Alt B — [template]
[tweet text]
[N] characters

Source used: [name + URL or "account voice only"]
```

## Thread pack

```
Voice: [handle] — [snapshot]
Brief: [topic] · thread
Structure: [breakdown | tension-resolution | sourced-explainer | story-turn | if-x-do-y]
Circuit: [primary + amplifier]
Slots: 1 hook · 2 stakes · 3… payload · N close

Recommended thread ([N] tweets)

1/ [text]
[N] ch · hook

2/ [text]
[N] ch · stakes

3/ [text]
[N] ch · payload

...

N/ [text]
[N] ch · close

Why this one: [structure + why the slots earn the tap]

Alt hook (same thread body):
[alternate tweet 1 only]
```

## Quote-tweet pack

```
Quoting: [handle] — [one-line summary of the original]
Quote text:
[text]
[N] characters
```

## Rules for the tweet block

- Paste-ready. No quotes wrapping the tweet unless the tweet itself contains quotes.
- No hashtags or emoji the Voice Card did not earn.
- Character count is visible characters as the user would paste them, including line breaks.
- If two variants share the same hook, kill one.
- If the user asked for one tweet, still show two alts unless they said "just one."

## After delivery

If the user picks a variant, tighten only that one. Do not regenerate the whole set unless they change the topic or account.
