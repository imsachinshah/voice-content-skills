## Scorecard

Score the live profile, then the rewrite.

| Part | Pass |
|---|---|
| Display name | Human ± one searchable signal, ≤50 |
| Bio | Beat + proof, ≤160, true, matches last 10 originals |
| Pin | Present, current beat, works as a standalone tweet |
| Link | One, real, matches conversion job — or honestly none |
| Location | Real or omitted |
| Header | Does not contradict the bio (note only) |
| Photo | Face readable at 48px (note only) |

Mark each pass / needs-work / fail. Rewrite fails first. Bio and pin always outrank header art.

## Two-second test

Read **only** name, bio, and pin.

A stranger in the niche should be able to say:

1. What this account posts
2. Whether it is for them
3. Why the next follow is not a random

If any answer is fog, rewrite the bio or the pin — not the handle.

## Feed-match

- Last 10 originals deliver the bio's promise
- Pin is not from a previous identity
- No credential the feed cannot cash
- Voice Card register matches bio register (do not put a hype bio on a reporter feed)

## Pre-send

Delete before shipping:

- [ ] Invented titles, revenue, "ex-Google"
- [ ] Keyword pipes
- [ ] Bio >160 or name >50
- [ ] Pin that needs the previous tweet to make sense
- [ ] Link that 404s or was guessed
- [ ] Second language with no feed in it
- [ ] "Building the future of"

## When to skip a field

- User said "just the bio" → do not force a name change
- Photo/header unknown → notes, not fake scores
- No strong original to pin → write a new pin and say to post it
- Thin feed → say so; prefer a restrained bio over a fake founder
